# Socio — платформа взаимопомощи

Vue 3 (Vite) + Node.js (Express) + SQLite (libSQL). Локально база — обычный файл, в продакшене — [Turso](https://turso.tech) (облачная SQLite, бесплатный тариф), поэтому данные не теряются при перезапусках и обновлениях.

- **Публичный сайт**: главная с живыми счётчиками, картой открытых заявок (без личных данных), направлениями помощи и формой «Стать волонтёром».
- **Кабинеты** для трёх ролей: администратор, помощник и человек, которому нужна помощь.
- **Живые обновления** через Server-Sent Events: назначение, принятие и выполнение заявки видны у всех сразу.
- Вход по телефону и паролю, права проверяются на сервере. Пароли хешируются (scrypt), неудачные попытки входа ограничены.
- Оценка помощника звёздами, жалобы, отказ от заявки, отмена, смена пароля, тёмная тема, мобильная вёрстка.

## Запуск локально

Нужен Node.js 22.13+.

```bash
npm install
npm run dev        # http://localhost:3000, горячая перезагрузка
```

Production:

```bash
npm run build && npm start
```

Демо-входы показаны на странице `/login`: вход в один клик под любой ролью. Пароль демо-аккаунтов `demo123`, у администратора `admin123`.
Чтобы пересоздать демо-данные, выполните `npm run seed`.

## Деплой

**Docker (любой VPS):**

```bash
docker compose up -d --build
```

База хранится в томе `socio-data`. Перед запуском поменяйте `ADMIN_PASSWORD` в `docker-compose.yml`.

**Render:** New → Blueprint → репозиторий. Всё настроено в `render.yaml`. Чтобы данные сохранялись на бесплатном тарифе, подключите Turso:

1. Зарегистрируйтесь на turso.tech и создайте базу (регион ближе к региону сервиса на Render).
2. Скопируйте URL базы (`libsql://…`) и создайте токен доступа.
3. В Render → Environment укажите `TURSO_DATABASE_URL` и `TURSO_AUTH_TOKEN`, затем Save → сервис перезапустится.

Таблицы создаются автоматически при первом запуске.

**Railway, Fly.io и любой хостинг с Dockerfile:** укажите переменную `DATA_DIR=/data` и подключите к `/data` постоянный том.

**Без Docker:** build-команда `npm install && npm run build`, start-команда `npm start`.

## Переменные окружения

Все необязательны, см. `.env.example`.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | порт |
| `TURSO_DATABASE_URL` / `TURSO_AUTH_TOKEN` | — | облачная база Turso; без них используется локальный файл |
| `DATA_DIR` | `./data` | где лежат локальная база и ключ подписи |
| `DEMO` | `true` | `false` — чистая база без тестовых данных и входа в один клик |
| `ADMIN_PHONE` / `ADMIN_PASSWORD` | `+998 77-010-25-56` / `admin123` | первый администратор |
| `SECRET` | генерируется | ключ подписи токенов |

## Структура

```
server/   Express API, SQLite/Turso (@libsql/client), авторизация, SSE
shared/   общие константы (районы, статусы)
client/   Vue 3 приложение (views, components)
prototype/ исходный HTML-прототип
```
